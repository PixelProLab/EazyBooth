# HiTi setup

Install the driver for the exact model and Windows version from [HiTi Download Service](https://www.hiti.com/support/download.aspx?MenuID=72&lang=EN). The operator Printing screen opens this official page. Vendor drivers are never silently installed or bundled.

Select the exact Windows queue, HiTi/Standard 4×6 and the loaded matching paper/ribbon kit. For the supplied NAMQ × Keeta frames choose **Portrait**, **Contain entire image**, borderless if supported, and one copy for the first test. Match these choices in Windows printing preferences. Switching queues resets the application paper preset to Automatic.

Print a test chart, capture and print each supplied frame, then print an older saved final and multiple copies. Inspect actual cut edges, sharpness, orientation, margins and copy count. Clear abandoned queued jobs deliberately before retrying uncertain jobs. The app never purges the Windows queue.

Windows acceptance is not physical completion. Automated tests use mock queues and do not certify drivers, USB, consumables or paper output. Consult the current vendor documentation for installation/compatibility; Misk's historical driver version is not imposed on reusable EazyBooth.
