# Operator guide

1. Install EazyBooth on Windows x64. Install camera/printer drivers separately. Create a private operator PIN on first launch.
2. Use the supplied NAMQ × Keeta profile, or create/duplicate an event. Each event has isolated settings, artwork and photographs.
3. Branding: import Welcome artwork; choose Cover/Contain. Choose Photo layout: Camera only (no artwork required), Background with camera window (import a background), or Frames (add frame choices and labels). Disabling frames keeps them saved for reuse. Frame PNG dimensions must match Layout's canvas. Imports survive removal of the source USB/Desktop file.
4. Layout: choose the canvas preset/custom size. Select the frame to calibrate; move/resize the camera rectangle visually or use Advanced controls. Adjust zoom, offsets and linked mirror. Branded Stage additionally uses background artwork. Save changes.
5. Camera: select the exact source, save and test live view. For Sony, wait until an actual scene appears and confirm it. Never confirm a logo. Test a capture; the camera remains connected when the booth launches.
6. Printing: select the queue, paper, orientation, fit, default copies and guest maximum. For the supplied frames select Portrait and Contain. Send a test, then physically inspect both frame designs on paper.
7. Readiness: check camera, confirmation, valid artwork, storage/free disk and printer. Capture a test photo and inspect the final. Launch Booth.

Guest flow: tap Welcome, choose a frame only when enabled, see the live composition, Start, countdown, review. Retake uses the same healthy camera stream and frame. Print 1 sends one copy; More Prints opens the touch quantity keypad. Done returns to Welcome. Accepted printing remains on review so guests can explicitly request more copies.

`Ctrl+Shift+G` → PIN → Saved Photos is the fast recovery route. The gallery is newest-first; open final/original, print, More Prints, Show in folder, or Open photos folder. Reprints use the saved final and current event printer settings. Locked users cannot browse guest photos. `Ctrl+Shift+A` opens profile administration; five taps in Welcome's top-right corner open operator access.

If a print result is unknown, inspect Windows queue before retrying. If camera fails, check power/USB and reconnect; reconfirm Sony. If settings are damaged, preserve the private backup and review recovered defaults before saving. Never delete an event's photos to fix a configuration problem.

Application-wide PIN authorization expires in main; idle operator UI locks after 10 minutes. Pending print submission holds navigation until its result. Back up the full private data directory with the app closed. Upgrading does not reset settings, PIN or photos.
