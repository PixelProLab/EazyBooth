# Sony / Imaging Edge setup

Use [Imaging Edge Desktop](https://imagingedge.sony.net/en/ie-desktop.html), [Imaging Edge Webcam downloads and supported cameras](https://support.d-imaging.sony.co.jp/app/webcam/en/download/), and [Sony webcam guidance](https://www.sony.com/electronics/support/articles/00247038) for current compatibility and model-specific setup. Official download buttons and shortcuts are provided; EazyBooth does not install vendor software.

1. Install the software appropriate for the actual Sony model and Windows version, following Sony's instructions and restart requirements.
2. Configure the camera for its supported PC/webcam connection. Use reliable USB data cabling and continuous power. Fully exit Imaging Edge Desktop Remote and other camera consumers before using Webcam in EazyBooth.
3. Ctrl+Shift+A → PIN → Camera → select the exact Sony source → Save → Test live view. Wait until a moving real scene replaces the utility logo. Confirm live scene before launching guests. Test focus/exposure and the actual delivered resolution.
4. Lock and launch. The camera remains warm behind Welcome and while guests choose frames. Retake reuses the stream. Reconnect invalidates confirmation; confirm again after verifying the real scene.
5. If a logo/black view persists, use Sony's documented reset procedure, check power/USB and reconnect. Device enumeration is not proof of a real scene.
6. Compare each frame's preview, saved photo and physical print with a real person/asymmetric chart. Run an event-length stability check on the actual kiosk.

EazyBooth captures Windows video frames. It does not include Sony native shutter/ARW support. Camera preferences do not guarantee delivered resolution. Autofocus is requested only when the driver exposes continuous focus and diagnostics do not promise unsupported behavior.
